# Troubleshooting & Common Fixes

Keep levels low while investigating. Change one thing at a time so you can identify the cause. Switch amplifiers off before reconnecting powered speaker cables.

| Symptom | Possible cause | Fix |
| --- | --- | --- |
| No sound anywhere | Playback stopped, wrong mix view, muted channels/main, or powered speakers off | Check source playback, input meter activity, channel/mix levels, main output meters, then speaker power/input. Follow the signal route in order |
| One source silent | Wrong input, cable fault, mute, low gain, or wrong laptop output device | Confirm the patch list; inspect the input meter; mute before reseating or substituting a known-good cable |
| Only one main speaker works | Missing L/R connection, wrong input setting, or pan/balance | Lower outputs; check both main meters, connections and approved speaker settings. Ask the lead before changing routing |
| Video vocals disappear / sound thin | Stereo feed incorrectly entering a balanced mono input, wrong adapter, or incompatible summing | Mute media; verify laptop mono and approved single-branch or summing route. Test left/right content; do not cure this by increasing gain |
| Video misses instruments or one side | Only one stereo side reaches the DI while laptop is still stereo | Enable and verify software mono or the correct summing device; test both sides before service |
| Buzz/hum from laptop | Cable/adapter fault, interference, or ground loop | Lower/mute the channel; inspect the route and DI. A DI ground-lift may help if fitted and used as instructed; never lift mains earth |
| Harsh/distorted sound / red clip | Laptop, mixer input, output, or amplifier driven too hard | Find the first overloaded stage and reduce it. If input clips, reduce source/gain or use the approved DI pad; keep levels controlled afterwards |
| Ringing / squealing | Microphone hearing main or monitor speaker | Immediately lower/mute the channel and monitor send; if uncertain lower/mute main and Aux 1. Correct placement before raising levels |
| Main sound works but monitors silent | Aux 1 sends/master down, wrong Samson input, or passive speaker connection missing | Check Aux 1 view/meters, sends, master, and approved Samson input/master. Power Samson off before checking powered speaker leads |
| Monitors change when mains change | Aux 1 may be post-fader or shared input gain changed | Ask the lead to verify pre/post configuration. Input gain can affect both mixes even with pre-fader sends |
| Tablet cannot control Ui16 | Wrong Wi-Fi/address, low battery, or connection loss | Check approved network and address, move into range, then use the tested backup device. Do not factory-reset the mixer |
| Feedback continues after mains muted | Aux 1/monitor feed still active | Lower/mute Aux 1 and the affected send; verify mute behaviour during the next soundcheck |
| Damaged plug, burning smell, or abnormal heat | Equipment/power fault | Stop using the affected equipment; isolate power safely, keep people clear, and contact the lead. Do not open or repair it during setup |

## Local problems and proven checks

| Symptom | Possible cause | Fix |
| --- | --- | --- |
| Recording button grey/cannot be pressed | USB unrecognised or wrong socket | While stopped, check MEDIA - REC and reinsert lanyard USB; wait for coloured availability, then start and verify active recording |
| Laptop audio very soft | DI pad at negative dB | Set laptop DI pad to **0 dB**, then check FreeShow/headphone output and channel 11; do not turn every control up blindly |
| Curtains/screen do not respond | Left-stage power off | Check plugs/switches beside curtains, then correct remote from back cupboard; keep clear of moving equipment |
| Projector blue power light off | Hidden outlet off/unplugged | Check behind hanging black curtain at centre rear stage wall |
| Projector powered but remote fails | Too far away or unreliable response | Use Epson remote at front, aim carefully and wait before retrying; ask lead if still failing |
| Mixer browser quick link fails | Wrong Wi-Fi/stale bookmark | Join mixer network and enter http://10.10.1.1 or http://ui-mixer.io in address bar |
| Control tablet battery low | Short battery life | Keep Dell charger connected to desk multiplug |
| Sermon absent from FreeShow | Sermons use PowerPoint | Open desktop **sermons** shortcut; Sune/Jacques prepares current file. Old files are in **archive**; confirm current file if unsure |
