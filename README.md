# ENH Church Sound System Guide

Complete setup guide, volunteer onboarding manual, troubleshooting playbook, and equipment inventory for our portable church PA system.

We meet in a school. Every Sunday, equipment comes out of school storage, is set up for service, and returns to storage afterwards. Use this guide in order on your first Sunday, with an experienced operator beside you.

**Status:** Hardware and existing laptop route supplied by the team; exact connections and approved settings marked **[TODO]** still need confirmation. Never guess a socket, power setting, or adapter wiring. Sound team lead/contact: **[TODO]**.
